# 🚀 Yousef Mohamed - Frontend Developer Portfolio

A modern, responsive, and high-performance personal portfolio website built with cutting-edge web technologies, featuring smooth animations and interactive user experiences.

---

## ✨ Features

- **Smooth Animations:** Powered by **GSAP** and **Framer Motion** with fluid scroll triggers and custom cursor effects.
- **Responsive Design:** Fully optimized for all screen sizes and devices.
- **Horizontal Project Scroll:** Showcase selected works with an immersive horizontal layout.
- **Interactive UI:** Dynamic phrases, active section tracking in the navigation bar, and scroll text reveals.
- **Direct Contact:** Integrated WhatsApp messaging form for quick and direct client communication.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (React)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [GSAP](https://gsap.com/) & [Framer Motion](https://www.framer.com/motion/)
- **Icons:** React Icons
